Pack 5 — Alliances (5-ALL)

144 distinct card names, 199 published printings. No other pack is required.
Use an updated game build containing the trusted Alliances implementations.
Enable through Options > Card Packs or the title-screen 5-ALL button.
Deck Builder > Extras filters this set independently of 1997 and Packs 1–4.

Build locally with tools/pack_5_alliances.py: fetch, fetch-art, build, verify.
The archive contains checked metadata and artwork, never executable scripts.
Each selected printing has an illustration crop and a full-card scan: these
are two views of the same printing, not two distinct playable cards.

Only construction source and metadata are distributed. Never distribute
the generated Pack-5-Alliances.zip or downloaded card artwork.
This optional pool does not alter the original decks or adventure balance.
Any digital adaptations are documented in Help and docs/simplified-cards.md.
