Pack 4 — Homelands (4-HML)

115 distinct card names, 140 published printings. No other pack is required.
Enable or disable this expansion in Options > Card Packs, or click 4-HML
beside the title-screen set strip. Deck Builder > Extras filters Homelands
independently of the original 1997 cards and the other packs.

The ZIP contains checked metadata and artwork, never executable scripts.
The trusted card rules must ship with a compatible game build. Artwork
includes an illustration crop and a full-card scan for each selected name.
Alternate printings are retained in metadata, not separate playable cards.

Build locally with tools/pack_4_homelands.py: fetch, fetch-art, build, verify.
The build is resumable and checks compatibility, file inventory and SHA-256.
Only construction source and metadata are distributed. Never distribute the
generated Pack-4-Homelands.zip or downloaded card artwork.

This optional expansion does not change the original 1997 decks. Its wider
card pool is opt-in; it is not a balance change to the original adventure.

Documented digital adaptation: Timmerian Fiends ownership exchanges accept
only nontoken cards. See the in-game rules text, Help and the simplified-card
ledger. Ownership remains distinct from battlefield control.
