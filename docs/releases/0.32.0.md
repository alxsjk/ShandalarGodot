# Shandalar 0.32.0

- **LAN duels and tournaments:** clearer hosting, discovery and compatibility messages; improved Tournament Hall; organiser pause/resume, confirmed result rulings/corrections and recoverable organiser controls.
- **Gameplay fixes:** card rules, cumulative upkeep, mana planning and AI decisions; better face-down/hotseat privacy, ability badges, extra land plays, regeneration and duel windows. Long names fit the LAN introduction with either skin.
- **Booster Draft and optional Packs 1–5:** stronger saved-pool verification and pack matching, alongside set filters, printing artwork and pack controls.
- Every game ZIP includes Python tools, metadata and instructions to construct **cardart.zip and Packs 1–5**. Card pictures and constructed packs are not distributed.

## Downloads

Choose **Apple Silicon Mac, Intel Mac, Windows x86-64, Linux x86-64, Raspberry Pi 5 / compatible ARM64 Linux, or Web**. Each has plain and `-with-skin` ZIPs; `original_skin.zip` is also available separately. Verify the thirteen ZIPs with **SHA256SUMS**.

Extract the whole folder. Desktop: place skin/card-art ZIPs in `skin/` and numbered packs in `cardpacks/`, beside the executable or Mac app; rescan and enable packs in **Options → Card Packs**. The base game needs no packs. See **CARD-ART-AND-PACKS.md** for construction commands. Web must be served over HTTP; numbered gameplay packs and LAN play are desktop-only.

LAN players need matching **0.32.0 builds and enabled packs** (protocol 20). Mac apps are ad-hoc signed, not notarized; Windows executables are unsigned.
