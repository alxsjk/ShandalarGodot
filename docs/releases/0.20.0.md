# Shandalar 0.20.0 — first comfortably playable duel release

Welcome back to the table!

Building on the 0.19.0 debut, this is the first ShandalarGodot release we
consider comfortably playable for **duels and deck building**. The core
duel experience is now substantially complete: build a deck, choose an
opponent, and enjoy early Magic. There will still be bugs to find and
details to improve, and your playtesting is very welcome.

**This is not the Shandalar adventure yet.** The world map, adventure and
Manalink online multiplayer remain future features. The online menu button
is a placeholder, not a working network mode.

## Strong play. Fair information.

We are proud of our solid **non-cheating AI player**. All four standard
difficulties—Apprentice, Magician, Sorcerer and Wizard—use fair information.
The stronger opponents study their own deck, adapt to its strategy, plan
spells and mana, and compare combat outcomes rather than simply ranking
individual creatures.

They do **not** read your unrevealed hand, either library's secret order,
future draws, or the random generator's state to choose a play. They get
no free cards, extra mana, or special rules. Hidden-information regression
tests protect this design. A stronger difficulty means stronger analysis,
not permission to cheat. The opponent remains fallible; this is not a claim
that it can never make a poor play.

For players who deliberately want something different, the separate,
opt-in **Unfair — sees your hand** challenge adds knowledge of your current
hand to Wizard. It is off on a fresh installation, clearly labelled,
unrated, and **not a fifth standard difficulty**. It still gets no future
draw knowledge, free resources, or rule exceptions.

Read the [fair-play contract](https://github.com/b0realis/ShandalarGodot/blob/v0.20.0/docs/fair-play.md)
for the precise boundaries.

## What you can play

- Full duels with the 897-card early-Magic pool and 319 included decks.
- Magic Battle against the computer, local hotseat, or computer-versus-computer demonstrations.
- Best-of matches with sideboarding, Gauntlet runs and sealed-deck building.
- The Deck Builder, with large cards on by default, responsive filters,
  keyboard card browsing, Enter to add and Backspace to remove.
- Combat timing and regeneration fixes, clearer animated-land stats,
  immediate damage-assignment markers, and more readable in-game help.
- Aswan Jaguar shows its chosen type behind the card, or "No creatures"
  when its opponent's library has no creature type available.
- More considered spell choices, deck preparation and combat planning.
- The headless Deck Lab for deck testing and reproducible simulations.

The playtested card placement and size are unchanged. Different screen
proportions may leave extra black space beneath the large card; the layout
keeps the cards consistent rather than stretching them.

## Downloads

Each platform has **two packages**. The plain ZIP is the standalone game
with its built-in fallback appearance; `-with-skin` includes
`skin/original_skin.zip` for the original look and sounds.

| Platform | Standalone | Original skin included | Start |
|---|---|---|---|
| Windows x86-64 | `Shandalar-0.20.0-windows64.zip` | `Shandalar-0.20.0-windows64-with-skin.zip` | Extract all files, open `Shandalar.exe` |
| Linux x86-64 | `Shandalar-0.20.0-linux64.zip` | `Shandalar-0.20.0-linux64-with-skin.zip` | Extract, run `./run.sh` |
| macOS, Apple Silicon + Intel | `Shandalar-0.20.0-macos.zip` | `Shandalar-0.20.0-macos-with-skin.zip` | Extract, open `Shandalar.app` |
| Web | `Shandalar-0.20.0-web.zip` | `Shandalar-0.20.0-web-with-skin.zip` | Serve the extracted folder over HTTP(S) |

`original_skin.zip` is also available on its own. `SHA256SUMS` lists the
checksums of all nine downloads. Source archives are available from GitHub.

Keep the whole extracted folder together. On macOS the `skin/` folder goes
**beside** the app, not inside it; on Linux and Windows it goes beside the
executable. Leave the skin ZIP intact. Linux and Windows packages target
x86-64, not ARM devices. The Mac app contains both architectures.

The Windows executable is unsigned. The Mac app is ad-hoc signed, not
Apple-notarized, so the operating system may ask you to approve opening it.
Only approve a download you trust; there is no need to disable system-wide
security settings. See the included README for platform-specific details.

For web, run `python3 -m http.server 8000` in the extracted folder, then open
`http://localhost:8000/`. Do not open `index.html` directly as a file.
The web package needs no cross-origin-isolation headers. Your browser keeps
settings, decks and imported packs in storage for that site's address;
export important decks before clearing it. These downloads are web-server
packages, not an announcement of a new hosted play site.

## Card pictures stay separate

**No package contains card pictures.** Choose your existing `cardart.zip`
in Options → Skin, or put it in the desktop game's `skin/` folder. The
included Python tools can fetch and assemble a pack for your own use:

```sh
python3 tools/fetch_card_art.py --out cardart/
python3 tools/mtg_assets.py --from-cardart cardart/ --out cardart.zip
```

For web, import your personal pack through Options → Skin. Do not upload
the card pictures with a public web build. You can also import the original
skin from your own game installation using the included tools.

## Testing and limits

The release gate passed 6,242 Godot tests and 231,734 assertions across
365 scripts, plus complete-duel smoke runs under modern and Fifth Edition
rules. The current layout and gameplay have been playtested on Linux;
macOS has also been playtested. The fresh Mac export passed startup with
and without the original skin and four headless Unfair duels on Apple
Silicon. The web export was checked in a desktop Chromium browser: startup,
duel setup and opening hand, original-skin loading, and Deck Builder
keyboard input. Missing optional art packs produce harmless HTTP 404
warnings in the browser console; the fallback appearance remains playable.

**Windows was cross-exported on macOS and has not yet been run on Windows.**
The universal Mac app's Intel half and real mobile devices also need native
community testing. Export checks are not a substitute for testing every
OS, graphics driver and browser.

Known rules simplifications remain listed in
[the fidelity ledger](https://github.com/b0realis/ShandalarGodot/blob/v0.20.0/docs/simplified-cards.md).
Please report problems with the platform, version, decks and duel seed
where possible. There is no claim that this milestone is bug-free.
