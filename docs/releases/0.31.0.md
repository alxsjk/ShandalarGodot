# Shandalar 0.31.0

- Optional packs: **1-tDotP, Fallen Empires, Ice Age, Homelands and Alliances**, with engine/AI support, printing artwork, set filters and pack controls.
- **SGManalink LAN play and tournaments**, including computer seats, plus **Booster Draft** integrated with enabled packs.
- Playtest fixes: long deck names stay inside save dialogs; text-changing effects such as Magical Hack have visible reminders; Kjeldoran Outpost's payment flow is clearer; moved combat windows stay put across phase changes.
- Every download includes Python tools and instructions for building **cardart.zip and Packs 1–5**. Card artwork and constructed packs are not distributed.

## Downloads

Choose **Apple Silicon Mac, Intel Mac, Windows x86-64, Linux x86-64, Raspberry Pi 5 / newer compatible ARM64 Linux, or Web**. Each has plain and `-with-skin` ZIPs; `original_skin.zip` is also available separately. Verify downloads with **SHA256SUMS**.

Extract the complete folder. Desktop: put skin/card-art ZIPs in `skin/`, and numbered packs in `cardpacks/`, beside the executable or Mac app. Rescan and enable packs in **Options → Card Packs**. The base game works without packs. For Web, serve the extracted folder over HTTP.

See the included **CARD-ART-AND-PACKS.md** for construction and setup. LAN players need matching builds and enabled catalogues. Mac apps are ad-hoc signed, not notarized; Windows executables are unsigned.
